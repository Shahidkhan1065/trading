# Al Ealami Trading

React website for Al Ealami Trading — converted from the Google Stitch design.

## Stack

- Vite + React + TypeScript
- Tailwind CSS v4
- React Router

## Pages

- `/` — Home
- `/about` — About Us
- `/trading-divisions` — Trading Divisions
- `/supply-chain` — Supply Chain & Logistics
- `/quality` — Quality & Compliance
- `/contact` — Contact Us / RFQ

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173
